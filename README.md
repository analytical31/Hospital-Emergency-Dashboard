# Hospital Emergency Room Dashboard | Power BI
## Project Overview
The Hospital Emergency Room Dashboard is an interactive Power BI dashboard designed to monitor and analyze emergency room operations, patient flow, waiting times, satisfaction levels, and department referrals. This dashboard provides healthcare administrators and hospital management with real-time insights to improve operational efficiency, patient experience, and resource allocation. </br>

## Project Objectives</br>
Analyze emergency room patient visits and trends.</br>
Monitor patient waiting times and service performance.</br>
Track patient satisfaction levels.</br>
Evaluate department referral distribution.</br>
Understand patient demographics by age group and gender.</br>
Measure on-time patient attendance and treatment efficiency.</br>
